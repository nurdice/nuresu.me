Connect Firebase to get started
Sprint Poker uses Firebase Realtime Database to sync votes across your team in real time. Setup takes under 5 minutes and is free for small teams.
1
Create a Firebase project
Go to console.firebase.google.com, click Add project and follow the prompts.
2
Enable Realtime Database
In your project, click Build → Realtime Database → Create database. Choose Start in test mode (you can tighten rules later).
3
Copy your Web app config
Go to Project Settings → Your apps → Add app → Web. Copy the firebaseConfig object.
4
Paste config into this file
Open backlog-refinement/index.html and find the FIREBASE_CONFIG section near the bottom. Replace the placeholder values with your config. Save & deploy.
